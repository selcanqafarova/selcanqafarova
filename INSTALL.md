# Continuous GitHub profile installation

Upload this entire folder to the profile repository:

`selcanqafarova/selcanqafarova`

Then open:

**Actions → GitHub Profile 3D Contributions → Run workflow**

The Action generates the Git Block contribution graph and automatically embeds it into the matching continuous terminal background.

Dynamic elements:

- Live visitor count: Komarev Profile Views Counter
- Stack icons: TypeScript, JavaScript, Swift, Python, C++, C#, HTML, CSS, Linux, Git and Figma for UI/UX
- Daily refreshed Git Block contribution graph
